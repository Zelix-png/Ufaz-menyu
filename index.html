Scientific Calculator

How to use it, step by step
Most scientific calculators (Casio fx-82/fx-991 style, the kind commonly used at UFAZ) share the same basic layout. Below is a labeled diagram of the keypad, followed by step-by-step instructions for the functions you'll use most.
1
Display — shows your input, mode and result.
2
SHIFT / MODE / ON / AC — SHIFT unlocks second functions; MODE switches modes; AC clears all.
3
Trig & root functions — sin, cos, tan, log, ln, √.
4
Memory keys — M+, M-, MR store/recall numbers; Ans recalls last answer.
5
Number pad & operators — digits, decimal, +/− sign, ÷ × − +.
6
= — calculates and shows the result.

1. Basic operations

Type the expression in order, then press =.

Example: 12 + 7 × 3

12+7×3=
Result: 33 — order of operations is applied automatically.

2. Parentheses ( )

Use parentheses to force a different order.

Example: (12 + 7) × 3

(12+7)×3=
Result: 57

3. Powers & roots

x² squares, x^y raises to any power, √ is square root.

Example: 5³

5x^y3=
Result: 125

Example: √49

√49=
Result: 7

4. Trig functions (DEG vs RAD)

Check the angle unit before using sin/cos/tan. Press MODE to switch DEG/RAD — most school problems use DEG.

Example: sin(30°)

sin30=
Result: 0.5
Tip: A wildly wrong trig result usually means the wrong DEG/RAD mode.

5. Logarithms

log = base-10, ln = natural log.

Example: log(1000)

log1000=
Result: 3

6. Fractions

a b/c enters exact fractions.

Example: 3/4 + 1/2

3a b/c4+1a b/c2=
Result: 1¼ (SHIFT + a b/c toggles decimal view)

7. Scientific notation (EXP)

EXP enters "× 10^" quickly.

Example: 3.2 × 10⁵

3.2EXP5=
Result: 320000

8. Memory & Ans

M+/M- add/subtract to memory, MR recalls it, SHIFT+MR clears it. Ans reuses the last result.

Tip: An "M" on screen means memory isn't empty — clear it before a new problem.

9. Clearing mistakes

AC clears everything; DEL deletes only the last character, so you can fix typos without starting over.
